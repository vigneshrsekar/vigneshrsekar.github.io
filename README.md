# Vignesh Sekar - Portfolio Website

This is the personal portfolio website for **Vignesh Sekar**, a Technical Team Lead with over 8+ years of experience in full-stack software development. The website showcases professional experience, skills, projects, domains, awards, and contact information.

## 🔗 Live Site

[https://vigneshrsekar.github.io](https://vigneshrsekar.github.io)

## 🛠 Tech Stack

- **HTML5** - Structure and content
- **CSS3** - Styling and responsive design
- **Bootstrap 5** - Layout and responsive grid system
- **JavaScript (Vanilla JS)** - Interactive components and animations
- **AOS (Animate On Scroll)** - Scroll-based animations
- **Swiper** - Carousel/slider for awards section
- **Glightbox** - Lightbox gallery functionality
- **Typed.js** - Typing animation effects
- **PureCounter** - Animated number counters
- **Isotope** - Filtering and layout
- **Moment.js** - Date/time calculations

## 📋 Sections

| Section       | Description                                    |
|---------------|------------------------------------------------|
| **Hero**      | Introduction with role and social links        |
| **About**     | Professional summary and personal details      |
| **Skills**    | Technology expertise across backend, frontend, database, cloud, DevOps |
| **Resume**    | Professional experience and education history  |
| **Projects**  | Portfolio of 10+ projects with tech stack used |
| **Domains**   | Industry experience areas (Inventory, Banking, Healthcare, etc.) |
| **Awards**    | Recognition and achievements across roles      |

| **Contact**   | Location, email, and phone                     |

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/vigneshrsekar/vigneshrsekar.github.io.git
   ```

2. Open `index.html` in your browser, or serve it locally:
   ```bash
   # Using Python
   python -m http.server 8000

   # Or using VS Code Live Server extension
   ```
